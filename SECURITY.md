# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub Security Advisories on
[tony1908/boxes-oss](https://github.com/tony1908/boxes-oss/security/advisories/new).
Include the affected version or commit, steps to reproduce, and the impact you
expect. We will acknowledge the report and coordinate a fix and disclosure
with you.
