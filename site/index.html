One VPS. A sandbox for every agent.

boxes runs isolated Ubuntu machines with a desktop, Docker and snapshots on a server you own. Your agents drive them from the CLI, the API or the SDKs.

curl -fsSL https://raw.githubusercontent.com/tony1908/boxes-oss/main/install/install.sh \
  | sudo bash -s -- \
  --domain boxes.example.com --email you@example.com

Free and open source (MIT). Ubuntu or Debian VPS, ports 80 and 443.

What's in a box

Desktop
An Ubuntu XFCE desktop you open with boxes desktop. Run GUI apps on it with boxes exec --desktop and capture it with boxes screenshot.
Docker
Docker runs inside the box, through Sysbox.
Snapshots
Saved every minute and on stop. Stop, resume, fork, or roll back to a snapshot with boxes restore.
Network
Allow all, deny all, or an allowlist of domains and CIDRs, changeable on a running box. Cloud metadata is always blocked.
Drives
Folders under /mnt that outlive the boxes using them. A drive mounts read-write into one box at a time, or read-only into many.
Users
Isolated Linux users with private homes, and shared group folders under /shared.
Agents
Claude Code, Codex, OpenCode, Pi, Prime and Kimi are preinstalled. Send a task with boxes prompt.
Access
SSH and scp into the box, and public HTTPS URLs for its ports with boxes host.
Control
A dashboard, an HTTP API, TypeScript and Python SDKs, webhooks, and API keys.

Install

Run the installer on a VPS you control, then install the CLI on your laptop.

  1. Point a domain at your VPS. Or skip DNS and use <your-ip>.sslip.io, which resolves to the VPS IP.

  2. Run the installer on the VPS. Replace the domain and email with your own.

    curl -fsSL https://raw.githubusercontent.com/tony1908/boxes-oss/main/install/install.sh \
  | sudo bash -s -- \
  --domain boxes.example.com --email you@example.com

  3. Open the one-time owner setup link the installer prints, and create the owner account. The setup token is also in /var/lib/boxes/admin.token.

  4. Install the CLI on your laptop, then log in with the owner account.

    curl -fsSL https://boxes.example.com/install/cli.sh | sh
boxes login --server https://boxes.example.com --email you@example.com

Requirements

  • Ubuntu or Debian, on amd64 or arm64, with root access.
  • Ports 80 and 443 open to the internet. Port 80 serves the Let's Encrypt challenge.
  • A DNS name that points at the VPS, or a sslip.io name.
  • CPU and RAM sized for the boxes you run. The installer sets no minimum.

Create a box and run a command

Create a box, which becomes current, then run a command in it.

boxes new --type small --ttl 3600
boxes exec current -- uname -a

Work on your repo

Copy a local project into the box, then run its tests there.

boxes push current . --to /config/project
boxes exec current -- bash -lc 'cd /config/project && npm test'

Run a long job

Start a command in the background, check its output, and stop it when you need to.

boxes exec current --detach -- npm run build
boxes ps current
boxes logs current <processId> -f
boxes kill current <processId>

Give an agent a task

Send a prompt to a coding agent that runs inside the box.

boxes prompt current "Fix the failing tests in /config/project" --provider opencode

Lock down the network

Allow only the domains a box needs when you create it, or cut its network off on a running box.

boxes new --network allowlist --allow-domain api.github.com
boxes update current --network deny-all

Start from a repo

Clone a Git repository into the box on first boot.

boxes new --git https://github.com/you/repo --revision main

Keep data between boxes

Create a drive, mount it into a box at /mnt/cache, and it keeps its files after the box is deleted.

boxes drive create cache
boxes new --mount cache:/mnt/cache

Undo with snapshots

List a box's snapshots, then roll the box back to one of them.

boxes snapshots current
boxes restore current <snapshotId>

Run a GUI app and see it

Start an app on the box desktop, then save a screenshot of the desktop.

boxes exec current --desktop --detach -- ./my-app
boxes screenshot current -o shot.png

Share a port

Give a port inside the box its own public HTTPS URL. Ports 3000, 3001 and 7070 are taken by the box, so serve your app on another port.

boxes host current 8080

Let your coding agent use boxes

Install the boxes skill for Claude Code, so the agent knows the CLI. Codex has its own --codex flag. OpenCode reads ~/.claude/skills too, so the same install works for it.

boxes skill install --claude
