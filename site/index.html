Open source · self-hosted

Sandboxes for AI agents, on your own server.

Create Ubuntu boxes with a desktop, Docker, and SSH access, drive them from the CLI, HTTP API, or SDKs, and keep their state in snapshots. Everything runs on one VM you control.

What you get

A full machine for every task.

Each box is an isolated Ubuntu machine. Choose its size, its lifetime, and what state to keep.

  • A real Linux desktop

    Ubuntu with XFCE, served through a browser. Open it with boxes desktop, or share a public URL.

  • Docker inside boxes

    Boxes run on Sysbox, so agents can build and run containers inside an isolated box.

  • Snapshots, stop, resume, fork

    boxes stop snapshots a box. boxes resume brings it back and boxes fork copies it for parallel work.

  • Timers and limits

    Set a time to live with --ttl, an inactivity stop with --idle-stop, or extend a box with boxes extend.

  • Agent harnesses

    Run prompts through Claude Code, Codex, OpenCode, Pi, Prime, or Kimi Code with boxes prompt.

  • Computer-use tools

    An MCP server gives agents screenshots, mouse and keyboard input, windows, and app launching on the desktop.

  • SSH, scp, and ports

    boxes ssh, boxes scp, and boxes forward reach a box. boxes host exposes a port at its own URL, public or private.

  • Dashboard, API, and SDKs

    Use the web dashboard, the /api/v1 HTTP API, or the TypeScript and Python SDKs.

Save reusable setup as environments with boxes env, receive box events through webhooks, and manage access with API keys.

Self-hosted install

Install on one VM.

One script installs Docker, Sysbox, the box image, and the Boxes server behind HTTPS.

Requirements

  • Ubuntu or Debian, on amd64 or arm64
  • Root access, for example through sudo
  • A domain pointing at the VM, with ports 80 and 443 reachable for Let's Encrypt
  • A contact email for the certificate

Optional flags: --host-base sets the host for box URLs, and --s3-endpoint with --s3-bucket stores snapshots in S3-compatible storage.

1. Run the installer on the VM

curl -fsSL https://raw.githubusercontent.com/tony1908/boxes-oss/main/install/install.sh | sudo bash -s -- --domain boxes.example.com --email you@example.com

2. Install the CLI on your laptop

curl -fsSL https://<your-server>/install/cli.sh | sh

Then run boxes login against your server to create boxes.

How it works

Three steps from VM to agent.

  1. 1

    Install on one VM

    Run the installer once. The server, agent, and box image are set up on that machine.

  2. 2

    Create boxes

    Start boxes from the dashboard, with boxes new, or through the HTTP API.

  3. 3

    Work in isolated desktops

    Agents run in their own desktops. State is saved in snapshots when you stop a box and on a regular interval.
